# TrafficTown

A top-down, living-city traffic simulation for mobile and desktop browsers.

## Development

The first playable browser prototype is being built in the `feat/traffic-town-foundation-001` branch. The public `main` branch is kept as a clean project entry point until the prototype is reviewed.

## Direction

- Strict 2D top-down presentation.
- Player designs and upgrades the road network.
- Residents, workplaces and traffic demand evolve autonomously.
- Diagnose congestion by inspecting individual vehicle routes.
- Public transport reduces private-car demand.
- Responsive browser-first architecture for Android, iOS and desktop.
